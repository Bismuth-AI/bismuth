# N313 — 300건, 축 예외 되돌린 뒤

채점표는 [README.md](README.md). 이 기록의 목적은 **결함을 항목별로 세는 것**이다.
L306~N314 아홉 라운드 동안 스코어카드만 보고 트리를 안 읽었고, 그 사이 판단은 전부 숫자
위에서 이뤄졌다.

## 셀 수 있는 것

```
실격선      통과 ✓        통과 폴더    0 ✓
한 층의 갈래  8 ✓          미분해 더미   2 ✗
깊이        5 ✗          가장 큰 잎   46 ✗
```

## A. 이름이 내용을 가리키는가

### A1 무관한 문서 혼입 — **5곳**

| 폴더 | 섞인 것 |
|---|---|
| `금융기관 규제 법령` (46건) | 공인회계사법, 공적자금관리 특별법, 공적자금상환기금법 |
| `금융 안정 및 감독` (11건) | 과학기술인공제회법 |
| `가상자산 이용자 보호` (5건) | 테러자금조달금지법, 온라인투자연계금융업법 |
| `기타 산업 구조` (4건) | 공적자금관리 특별법 시행령, 소비자생활협동조합법 |
| `개인금융채권 보호` (13건) | 금융소비자 보호에 관한 법률 |

### A3 나열식 이름 — 0

## B. 형제가 서로 배타적인가

### B1 겹치는 형제 쌍 — **3쌍**

- `금융 및 자본` ↔ `금융 안정 및 감독` ↔ `금융 지원 및 산업별 금융` — 셋이 서로의 후보
- `개인금융채권 보호` ↔ `금융 안정 및 감독` — 금융소비자보호법이 양쪽에 걸린다
- `과학기술 및 연구개발` ↔ `과학기술 및 우주항공` — 유공자·조직 법령이 어느 쪽인지 이름으로 갈리지 않는다

## C. 노트만으로 배제할 수 있는가

### C1 `<축>: <이름>` 대체 노트 — **2곳**

```
기술개발 촉진 법령   ↳ 기술 분야: 기술개발 촉진 법령
금융기관 규제 법령   ↳ 금융기관 유형: 금융기관 규제 법령
```

로그의 표지 거부와 정확히 맞는다: `sign is the folder name again` **20건**,
`no sign was proposed` 10건, 길이 초과 2건. 표지 수정 후에도 이름 반복이 남아 있다.

### C2 재고 목록 노트 — 1곳

`산업별 육성·지원·구조조정 ↳ 특정 산업 분야(1인 창조기업, 4차산업혁명, 가상융합, 경영/기술지도, 회계, 이공계, 규제특구, 기업…`

## D. 금지된 이름

**D1 잔여 + D2 부정 정의 — 같은 폴더 1곳**

```
기타 산업 구조  ↳ 가맹사업거래와 대·중소기업 상생협력 외의 특정 산업 구조를 규율한다
```

이름이 "기타"이고 노트가 "~ 외의"다. 두 규칙 다 프롬프트에 있는데 통과했다.

## 이 라운드가 확인해 준 것

**46건 잎 `금융기관 규제 법령`은 질문을 딱 한 번 받았고 그때 거부됐다**(`axis already used
above here`). 그리고 그 안에는 공인회계사법·공적자금 법령이 들어 있다 — 이름이 부정하는
내용이다.

L308의 37건 잎에서 본 연쇄가 그대로 반복된다:

```
구성원 판단이 이름과 안 맞는 문서를 받아들임
  → 이름이 내용을 부정하는 폴더
    → 정직한 하위 축이 없음 → 거부
      → 큰 잎으로 고정
```

표지를 구성원 질문에 넣는 수정은 들어갔지만, `sign is the folder name again`이 20건이다.
**표지가 이름과 같으면 표지를 넣어도 이름만 보는 것과 같다.** 그 20건이 지금 이 연쇄의
입구이고, 다음 실험은 거기서 시작해야 한다.
